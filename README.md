# Crom OmniFiles

Bem-vindo ao Crom OmniFiles, um gestor de ficheiros moderno e performant construído com React e Vite.

## Estrutura do Projeto

- **`app/`**: Código-fonte da aplicação React.
- **`docs/`**: Documentação técnica e guias de contribuição.

## Como Iniciar

1.  Navegue para a pasta da aplicação:
    ```bash
    cd app
    ```

2.  Instale as dependências:
    ```bash
    npm install
    ```

3.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    ```

A aplicação estará disponível em `http://localhost:5173`.
